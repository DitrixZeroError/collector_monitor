# Сервис прогнозирования инцидентов инженерных коллекторов Москвы

Веб-приложение для диспетчера. Показывает объекты на карте Москвы, датчики объекта и их показания, а также прогноз пожарного риска от ML-модели.

## Запуск

Нужен Python 3.10 или новее и доступ в интернет: карта OpenStreetMap и библиотека Leaflet загружаются онлайн.

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

Откройте в браузере http://127.0.0.1:5000

| Логин        | Пароль     | Роль          |
|--------------|------------|---------------|
| `admin`      | `admin123` | Администратор |
| `dispatcher` | `disp123`  | Диспетчер     |

Смените эти пароли в разделе «Настройки → Пользователи».

При первом запуске создаётся база `data/collector_monitor.sqlite3`. Справочники объектов и датчиков заполняются из `data/seed/`. Чтобы начать с чистого листа, остановите приложение и удалите файл базы.

## Как увидеть прогноз

1. Войдите как `admin`.
2. Откройте «Настройки → Модель прогнозирования».
3. Загрузите `fire_risk_model_v2.joblib` и нажмите «Включить прогнозирование».
4. Откройте «Настройки → Эмуляция» и выберите журнал. Пример `журнал_событий_пример.csv` уже лежит в списке. Выберите скорость и нажмите «Запустить эмуляцию».
5. Перейдите на «Рабочее место»:
   * на карте отметки меняют цвет;
   * по нажатию на объект видны его датчики и показания;
   * справа показан прогноз по объектам.

Прогноз пересчитывается в конце каждого модельного часа.

## Структура проекта

app.py                  точка входа, сборка приложения
config.py               пути, константы, пользователи по умолчанию
database.py             схема базы, начальное заполнение справочников
auth.py                 вход по логину и паролю, проверка прав
routes_api.py           рабочее место диспетчера и JSON-API для него
routes_settings.py      раздел «Настройки»: справочники, модель, эмуляция
services/
  event_classifier.py   что означает показание датчика: риск, присутствие, неисправность
  feature_builder.py    почасовые признаки для модели
  model_service.py      загрузка .joblib и получение прогноза
  emulator.py           проигрывание журнала событий в ускоренном времени
  external_data.py      импорт горячих работ, погоды и реестра инцидентов
  prediction_settings.py  включён ли прогноз и какая модель выбрана
templates/              HTML-страницы (Jinja2)
static/css, static/js   оформление и скрипт рабочего места
data/seed/              исходные справочники (CSV)
data/uploads/           загруженные модели и журналы
